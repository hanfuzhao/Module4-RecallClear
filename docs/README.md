# Documentation

- [`slides.pptx`](slides.pptx) — the 8-slide deck in PowerPoint format, for submission or presenting from PowerPoint/Keynote. Regenerate with `python -m scripts.make_deck`.
- [`slides.html`](slides.html) — the same deck as self-contained HTML. Open in a browser, press **F** for fullscreen, **→** to advance, `#5` in the URL jumps to slide 5.
- [`pitch_script.md`](pitch_script.md) — the spoken script, matched slide-for-slide, ~610 words ≈ 5:00 at a slow pace.
- [`pitch.md`](pitch.md) — the longer outline the script was distilled from, with sourcing for every number.
