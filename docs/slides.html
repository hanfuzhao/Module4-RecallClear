The result I'm proudest of Innovation 2 · a replicated negative

We trained it twice to say
"STOP DRIVING." It wouldn't.

  • Run 1, uniform data: rare-warning recall 0%
  • Run 2, rare cases ×8 (16% of the mix): still 0% — even on letters it trained on
  • Why: the warning is 3 tokens out of ~130. Token-averaged loss never feels it.
  • Class imbalance wasn't the problem. Token imbalance was.
eval loss 0.05 — and still silentreplicated, not anecdotal
