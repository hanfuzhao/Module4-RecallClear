# Raw data

`nhtsa_recalls.jsonl` (11,677 notices, ~25 MB) is downloaded here by
`make data` and is deliberately git-ignored: it is a byte-for-byte
reproducible export of a public dataset, so committing it would bloat the
repository without making anything more reproducible.

Source: [NHTSA Recalls Data](https://data.transportation.gov/d/6axg-epim),
U.S. Department of Transportation open data (public domain).
